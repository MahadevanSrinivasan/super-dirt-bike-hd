# 🏍️ Super Dirt Bike HD: Motocross & Trials

An original **1080p 60fps Web + 720p HD Native RetroPie (SDL2 OpenGL ES 2.0)** dirt bike game combining childhood classics:
1. **⛰️ Physics Trials & Stunt Obstacle Mode** (*Miniclip Dirt Bike / Elasto Mania / Trials* style):
   - Two-wheel spring-damper suspension physics over boulder piles, giant timber logs, seesaw bridges, whoops, and mega-ramps.
   - Pull **Wheelies (`+250`)**, **360° Backflips & Frontflips (`+1000`)**, and **Slope-Matched Perfect Landings (`+500`)** without crashing your rider!
2. **🏁 Excitebike-Style 4-Lane Stadium Motocross GP**:
   - Switch between 4 stadium lanes (`↑` / `↓`), hold **Turbo Boost (`Z` / `Shift`)** while managing the **Engine Temperature / Overheat Gauge**, hit **Cooling Chevron Arrows (`>>>`)**, dodge mud pits, and clip AI rival riders with your rear wheel!
3. **🛠️ Custom Track Builder**:
   - Add or remove track segments (`Flat`, `Med Jump`, `Mega Ramp`, `Tabletop`, `Whoops`, `Rock Pile`, `Giant Logs`, `High Bridge`, `Mud Patch`, `Turbo Cool`) using keys `1–0` or clicking the palette bar, and test-ride your custom course immediately!

## Controls
| Action | Keyboard | Mobile Phone | RetroPie Gamepad |
| :--- | :--- | :--- | :--- |
| **Gas / Throttle** | `Right Arrow` / `D` / `Space` | Hold Right Half / `GAS` | `A` / `B` |
| **Turbo Boost** | `Z` / `Shift` | Upper-Right / `TURBO` | `X` / `Y` |
| **Brake / Reverse** | `Left Arrow` / `A` | `BRAKE` | `D-Pad Left` |
| **Lean Back / Flip (Trials) or Lane Up (GP)** | `Up Arrow` / `W` | Slide Left/Up or Tilt Phone | `D-Pad Up` |
| **Lean Forward (Trials) or Lane Down (GP)** | `Down Arrow` / `S` | Slide Right/Down or Tilt Phone | `D-Pad Down` |
| **Switch Game Mode** | `Tab` / `M` | Top Bar Mode Buttons | `L` / `R` Shoulder |
